# CIDA Research Tools Knowledge Base

This website holds CIDA's coding guidelines as well as tutorials and other information from the CIDA Research Tools Committee.

---

## Getting Started

If you are a new CIDA employee, we recommend you start by:

1. Reviewing the [CIDA Coding Guidelines](coding_guidelines.md) and [CIDA Data Storage Guidelines](data_storage.md).
2. Installing `git` and reviewing the [Git Tutorial Series](git/github_setup_01.md).
3. Installing the [CIDAtools](https://github.com/CIDA-CSPH/CIDAtools) R package and reviewing the [documentation](https://cida-csph.github.io/CIDAtools/).
4. Reviewing the [Computing Resources](computing/CIDA_computing_resources.md) available to CIDA members. 

## Other Resources

There are various other articles and resources which can be accessed via the sidebar or the search box:

CIDA members who work on large-scale data analyses may benefit from reading about:

  - The [Alpine HPC](computing/alpine.md) system for large-scale analysis on deidentified/non-PHI data. 
  - The [CSPH Biostats Cluster](computing/CIDA_BIOS_Cluster.md) for large-scale analysis with sensitive/PHI data.
    - The CSPH Biostats Cluster can also be configured for [interactive coding](computing/CIDA_BIOS_Cluster_Interactive_IDEs.md) in RStudio or JupyterLab
